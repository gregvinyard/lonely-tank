# Art Requests & Log

All art is generated by the coding agent with PixelLab (via MCP) at development time, or drawn in code as a placeholder. The game never calls PixelLab at runtime.

**How art is wired in:** every texture is listed in `src/data/assets.ts`. Setting an entry's `file` to `assets/<name>.png` (served from `public/assets/`) replaces the placeholder. Gameplay code only uses the texture key.

**Conventions**

- Strict top-down view, no perspective or isometric angle.
- Muted sci-fi wasteland palette: warm rust and sand, with cool teal and violet tech accents.
- Rotating sprites (tank hull, turret) face **right (+X)**, centered on the canvas; the rotation pivot is the canvas center.
- Transparent background unless noted.

## Generation log

### What works with PixelLab for this game

- **Text-only prompts drift to 3/4 perspective.** Even with "directly from above", `create_image_pixflux` returned a 3/4-view tank with the turret attached.
- **Image-to-image from the code placeholder works well.** Feeding the placeholder as `init_image` locks in the strict top-down view, composition, and facing. `init_image_strength` ~60 adds lots of detail; ~120–130 stays close to the input.
- **Upload init images instead of pasting base64.** A large base64 string got corrupted in transit; `get_upload_url` + `init_image_url: upload:<id>` is reliable.
- **Forced palette keeps parts consistent.** Passing the finished hull as `color_image` made the turret match it.

## UI kit (code-drawn)

Frames (`ui_panel`, `ui_plate`, `ui_button*`, `ui_bar`) and 9×9 HUD icons (`icon_hull`, `icon_fuel`, `icon_circuit`, `icon_warn`, `icon_up`) are pixel maps in `src/data/uiKit.ts`, drawn at boot. PixelLab's UI panel tool makes 192–688 px panels, far bigger than this game's ~400 px-tall view, so small frames are hand-drawn to stay on the pixel grid. PixelLab will be used for the larger upgrade icons (M7).

## Sound

Sound effects are samples generated with **Mirelo** (`text_to_sfx`), played through WebAudio by `src/audio/sfx.ts`. Files are in `public/assets/sfx/`. Until a file has loaded (or if one fails), the old synthesized blip plays where there is one. M toggles mute (remembered in `localStorage` under `lonely-tank.muted`).

Processing (scratchpad script, recorded here):
- **One-shots:** trimmed to 3 ms before the first sound and 40 ms past the last (with a fade), peak-normalised to −1 dB, then mp3 at 96 kbps mono. Levels are balanced in code by the `gain` in `SAMPLES`.
- **Loops:** only gain-normalised, never trimmed or faded, and shipped as WAV so the seam stays clean (mp3 padding would click). The wind was resampled to 22,050 Hz with an FFT resample, which treats the clip as periodic.
- Sounds that repeat a lot get ±5% pitch variation and pick from two takes. Some are rate-limited (`minGapMs`).
