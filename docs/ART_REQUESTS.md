# Art Requests & Log

All art is generated by the coding agent with PixelLab (via MCP) at development time, or drawn in code as a placeholder. The game never calls PixelLab at runtime.

**How art is wired in:** every texture is listed in `src/data/assets.ts`. Setting an entry's `file` to `assets/<name>.png` (served from `public/assets/`) replaces the placeholder. Gameplay code only uses the texture key.

**Conventions**

- Strict top-down view, no perspective or isometric angle.
- Muted sci-fi wasteland palette: warm rust and sand, with cool teal and violet tech accents.
- Rotating sprites (tank hull, turret) face **right (+X)**, centered on the canvas; the rotation pivot is the canvas center.
- Transparent background unless noted.

## Generation log

### What works with PixelLab for this game

- **Text-only prompts drift to 3/4 perspective.** Even with "directly from above", `create_image_pixflux` returned a 3/4-view tank with the turret attached.
- **Image-to-image from the code placeholder works well.** Feeding the placeholder as `init_image` locks in the strict top-down view, composition, and facing. `init_image_strength` ~60 adds lots of detail; ~120–130 stays close to the input.
- **Upload init images instead of pasting base64.** A large base64 string got corrupted in transit; `get_upload_url` + `init_image_url: upload:<id>` is reliable.
- **Forced palette keeps parts consistent.** Passing the finished hull as `color_image` made the turret match it.

### tank_hull.png (v1)

- Tool: `create_image_pixflux`, 64×64, no_background, view "high top-down", single color black outline, medium shading, highly detailed, seed 31
- init_image: code placeholder hull, strength 60

- Post-processing: mirrored horizontally so the wedge-shaped nose faces +X.
- Opaque bounds 40×38 px, centered; collision circle radius 20.

### terrain_ground.png (v1)

- Tool: `create_topdown_tileset` (standard), 32×32 tiles, high top-down, lineless, basic shading, medium detail, transition 0.25
- Lower: "dusty rust-orange alien desert sand with tiny pebbles, flat and calm, low contrast"; upper: "darker cracked dry red-brown hardpan earth with fine cracks, low contrast"
- Used only the single-terrain sand tile (the Wang tiles join seamlessly with themselves). The transition patches had dark rims that read as pits/obstacles, so they're not used.
- Post-processing: colour-graded toward the old muted sand (saturation ×0.58, value ×0.82, hue pulled toward orange-brown).
- `BootScene` lays the tile out 8×8 with seeded mirroring into a 256 px `terrain` texture so the repeat isn't noticeable.

### rock.png, rock_2.png, rock_3.png (v1)

- Tool: `create_image_pixflux`, 64×64, no_background, high top-down, black outline, medium shading, highly detailed
- init_image: hand-drawn guides (violet-grey boulder lit from the top-left), strength 70–80
- Prompt: "top-down alien boulder seen from directly above, weathered dusty violet-grey stone with cracks and facets, small rust-colored mineral flecks, lit from the top-left, soft shadow on the bottom-right" (`rock_3`: "cluster of two alien boulders")
- `rock.png`: seed 92. `rock_2.png`: seed 93, `rock.png` as forced palette. `rock_3.png`: seed 94, same palette; a few stray text-like pixels at the bottom-left were erased.
- Rejected: seed 91 with the spaceship as palette (came out flat grey).
- The variant and mirroring come from each rock's seeded angle, so the world stays deterministic.

## Sound

All sound effects are synthesized in code with WebAudio (`src/audio/sfx.ts`): no audio files. Fire, shell impact, drone hit, explosion, tank hit, pickup, workshop open/ok/deny/craft, rescue, low-fuel beep. M toggles mute (remembered in `localStorage` under `lonely-tank.muted`).

Generations used so far: 24 of 2000 this cycle.
