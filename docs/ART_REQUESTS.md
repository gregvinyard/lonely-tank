# Art Requests & Log

All art is generated by the coding agent with PixelLab (via MCP) at development time, or drawn in code as a placeholder. The game never calls PixelLab at runtime.

**How art is wired in:** every texture is listed in `src/data/assets.ts`. Setting an entry's `file` to `assets/<name>.png` (served from `public/assets/`) replaces the placeholder. Gameplay code only uses the texture key.

**Conventions**

- Strict top-down view, no perspective or isometric angle.
- Muted sci-fi wasteland palette: warm rust and sand, with cool teal and violet tech accents.
- Rotating sprites (tank hull, turret) face **right (+X)**, centered on the canvas; the rotation pivot is the canvas center.
- Transparent background unless noted.
